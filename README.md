# PMS Monorepo

This repository is organized as a two-app monorepo:

- `PMS-FE`: React + Vite frontend
- `PMS-BE`: NestJS + Prisma backend

## Root Scripts

- `npm run fe:dev`
- `npm run fe:build`
- `npm run be:dev`
- `npm run be:build`
- `npm run be:prisma:generate`
- `npm run be:prisma:migrate`
- `npm run build`

## Frontend

Frontend app lives in `PMS-FE`.

## Backend

Backend app lives in `PMS-BE`.
